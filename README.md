# Personal-Trading-Journal
A trading journal web application used to track and gather insights through trading transactions data.

## Features
### Trade Logs
Performs all of the CRUD Operations for logging and tracking the trades. It gives info about whether the specific trade resulted in a WIN or a LOSS. The balance in the portfolio is also being automatically updated when a trade is logged ensuring that profits or losses are reflected.
