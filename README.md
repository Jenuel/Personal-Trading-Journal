# Personal Trading Journal

**Personal Trading Journal** is a microservice web application used to track trading performance and gain useful insights from trading transaction data.

This project also demonstrates the power of the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/introduction) by allowing a large language model (LLM) to understand the structure and context of the application's database. This way, enhances the quality and relevance of AI-generated insights.
